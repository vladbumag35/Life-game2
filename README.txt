Это полноценная мобильная версия с:
- вертикальным XP bar;
- званиями;
- быстрыми действиями;
- кастомным XP;
- историей;
- статистикой;
- сохранением XP в браузере;
- iPhone safe-area и touch UI.

ВАЖНО ДЛЯ iPHONE:
Чтобы добавить это как настоящее веб-приложение на экран «Домой», файлы нужно разместить на HTTPS-сайте/хостинге.
После открытия сайта в Safari: Поделиться → На экран «Домой».

Если открыть index.html локально из «Файлов», Safari может показать страницу, но установка PWA как приложения локально не работает.
